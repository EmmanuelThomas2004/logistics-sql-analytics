# Logistics SQL Analytics

A SQL analytics project focused on analyzing logistics and delivery operations using practical business problems.

## Overview

This project uses SQL to analyze shipment and delivery data and generate insights into delivery performance, logistics providers, shipping costs, warehouse operations, and vehicle utilization.

## Analysis Covered

* Average delivery time by region
* Late delivery percentage by logistics provider
* Top destinations by shipping cost
* Warehouse shipment volume
* Vehicle delivery performance and average distance

## Files

* `logistics_data.sql` — Creates the required tables and inserts sample logistics data.
* `logistics_analysis.sql` — Contains SQL queries for logistics analytics.

## SQL Concepts

* SELECT
* WHERE
* GROUP BY
* HAVING
* ORDER BY
* Aggregate Functions
* CASE WHEN
* DATEDIFF
* LIMIT

## Purpose

The project is designed to strengthen SQL skills and demonstrate practical data analysis techniques relevant to Data Analyst and Logistics Analyst roles.
